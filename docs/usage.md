# 使用与迁移

简体中文 · [English](en/usage.md)

首次进入会显示“欢迎建造你的记忆宇宙”，先选择简体中文或 English，再配置云端模型或进入工作区。语言偏好和完成状态保存在当前浏览器中，后续进入不用重复选择。

## 从聊天开始

在 **工作台** 中告诉助手你学到的知识、做过的事情或希望保留的想法。新会话和历史会话位于对话窗口顶部。点击停止可以中断当前回答，已经收到的文本会保留。

每轮成功聊天结束后，后台判断哪些内容值得保留。不要求每条消息都生成文档；计划不会写成已完成的经历，助手提供的解释也不会自动写成你已经学会的知识。自动整理默认开启，可以在 **设置 → 自动整理** 中关闭。

会话中显示整理结果。也可以打开 **知识宇宙 → 整理与确认**，查看已整理、跳过、待确认和失败的任务。失败后检查配置与网络，再明确重试；重试可能再次调用模型。

## 文档与标签

知识库每篇文档围绕一个主题，后续同主题内容会补充到已有文档。必要的小知识点可以成为独立文档，并通过高亮标题互相连接。

左侧目录树按归档位置浏览文档；标签可以跨目录筛选，一篇文档可以有多个标签。在 **标签池** 中可以新增、修改和删除标签。删除标签会移除分类关联，笔记正文仍保留。

按标题找文档，或用记忆检索找具体章节。助手回答时也会使用标签、关键词和章节寻找相关内容，只发送有限的相关上下文给模型。检索结果有覆盖范围，不能将有限摘录当成整年所有记录。

## 自己修改

打开文档后点击编辑，可以修改标题、正文、出处、目录和标签。未填写出处时按日期记录，不要求自己编造来源。

普通自动补充会保留人工正文。明确的更正通过局部替换修改当前结论，并保留历史；有歧义时先等待你确认。待确认内容不会被当作已确认的最新事实。

在 **整理与确认** 中可以确认建议、忽略，或补充说明后重新整理。版本冲突时读取最新原文，核对后再保存，避免覆盖另一处已经发生的修改。

历史版本可以阅读或取作编辑草稿。草稿只保留在当前打开的页面会话中，关闭、刷新前请保存。

也可以使用外部编辑器修改本地 Markdown。回到文档后核对外部变更，确认导入后更新应用索引。请保留文件的内部 ID 和元数据；归档目录应在页面上修改，不要直接重命名 `notes/topics/` 中的文件。

删除文档会删除其正文和历史版本。原始聊天单独保存，删除文档不会删除相应聊天。

## 关系星图

打开 **知识宇宙 → 关系星图**，查看真实文档节点与已经确认的关系。点击节点查看文档，点击关系查看证据；拖动节点或空白区域，使用缩放和复位调整视图。

星图使用力导向布局，蓝白光晕中的明亮星点代表文档，纤细的星座连线代表关联。节点的权重按不同关联文档的数量计算，关联越多，星点越大；每个节点都有文字标签。鼠标悬浮时照亮当前节点、相邻文档及连线。

节点在关联力、排斥力和碰撞约束下缓慢漂移。拖动某个节点时暂时固定它，松开后继续参与物理模拟；拖动画布可以平移，滚轮或缩放按钮可以调整视图。可用 **暂停运动 / 继续运动** 手动控制，用 **复位星图** 恢复布局与缩放。后台、弹窗打开或图谱不可见时暂停；减少动画模式使用静态布局，拖拽与缩放仍可用。

没有笔记时显示空状态；还没有关系的文档以独立星点展示。点击 **探索星图** 可以体验知识连接、节点查看、拖拽和缩放；体验内容只在界面中展示，不写入真实记忆库，也不调用云端模型。切换 **我的知识** 返回自己的文档关系。

星图以文档为节点，目前不提供任意人物、地点等实体的独立图谱。

## 备份

在 **设置 → 记忆包与恢复** 中点击导出，下载 ZIP。包中包含对话、标签、笔记、历史版本、文档关系和整理任务，不包含 API Key 或模型配置。

导出包没有加密。它包含个人资料，请在自己信任的位置保管。不要只保存 Markdown 而漏掉会话与数据库。

## 换机器或恢复

1. 在旧电脑导出 ZIP，并复制到新电脑
2. 在新电脑安装并启动MemoCosmos
3. 在设置页选择 ZIP，确认恢复到新库
4. 复制页面返回的记忆库绝对路径
5. 关闭当前服务，在项目根目录指定该目录重新启动

```sh
uv run --project backend --no-sync python run.py --memory-dir '/绝对路径/恢复后的记忆库'
```

恢复会创建新的持久目录，不覆盖当前记忆库，也不会自动切换。导入后未完成的旧任务不会自动调用模型，可以核对后选择重试。

新电脑需要重新配置 API URL、模型名称和 API Key。在同一台电脑恢复时，独立的模型配置可以继续使用。

## 界面与动画

界面采用深色星空背景，页面、文档状态与弹窗使用连续过渡，按钮提供轻微反馈。

点击右上角语言按钮，可在 **简体中文** 与 **English** 之间切换。语言选择保存在当前浏览器中，页面日期也随界面语言显示。自己的文档、标签和聊天内容保留原语言；切换语言不会修改记忆库。

在 **设置 → 视觉与动画** 中可以开启减少动画；同时遵循系统的减少动态效果偏好。手动设置在本次打开期间有效。
