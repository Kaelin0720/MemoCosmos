# MemoCosmos interface

For installation, API configuration, and daily use, start with the [English guide](../README.md) or [中文指南](../README.zh-CN.md).

The named release package includes the built interface. A source installation builds this directory with `pnpm install --frozen-lockfile` and `pnpm build`, then uses the root launcher. API Keys belong in the local Settings page, never in a `NEXT_PUBLIC_*` variable.
